NAME

qmail-control - qmail configuration files

INTRODUCTION

You can change the behavior of the qmail system by modifying qmail's control files in /var/qmail/control.
qmail can survive with just one control file, me, containing the fully-qualified name of the current host. This file is used as the default for other hostname-related control files.
Comments are allowed in badhelo, badmailfrom, badmailfromnorelay, badrcptto, badrcpttonorelay, locals, percenthack, qmqpservers, rcpthosts, smtproutes, and virtualdomains. Trailing spaces and tabs are allowed in any control file.
